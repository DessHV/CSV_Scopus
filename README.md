# Dashboard Scopus - Instagram y Desarrollo Social

Aplicación web desarrollada en Streamlit para analizar artículos científicos exportados desde Scopus.

## Pregunta de investigación

¿Cómo influye el uso de Instagram en el desarrollo social de adolescentes y jóvenes?

## Keywords

- Instagram
- Social Development
- Adolescents
- Social Media

## Funcionalidades

- Carga dinámica de CSV local.
- Lectura opcional desde URL RAW de GitHub.
- Uso de CSV incluido en el proyecto.
- Métricas generales del dataset.
- Publicaciones por año.
- Artículos más citados.
- Revistas o fuentes más frecuentes.
- Tipos de documento.
- Estado de acceso abierto.
- Autores más frecuentes.
- Keywords y palabras recurrentes en abstracts.
- Tabla filtrable y descarga del dataset filtrado.

## Ejecución local

```bash
pip install -r requirements.txt
streamlit run app.py
```

## Despliegue en Streamlit Community Cloud

1. Subir este proyecto a GitHub.
2. Entrar a https://share.streamlit.io/
3. Conectar el repositorio.
4. Seleccionar `app.py` como archivo principal.
5. Desplegar.
